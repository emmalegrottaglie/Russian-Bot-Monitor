# Before a chart goes public

Run through this for every new chart. Each line links back to the reasoning in this folder.

## Says what it is

- [ ] The value axis has a short, horizontal title naming the unit (01).
- [ ] Short units are on the tick labels: %, PP, / H (01).
- [ ] An index chart names its base period by its dates: "100 = AVERAGE 09-15 TO 10-07" (01).
- [ ] Percent and percentage points are not mixed up (01).
- [ ] Lines are labelled directly at their ends, not only in a legend (01).
- [ ] Events are dashed vertical lines with short labels, and each event has a source and a status (reported or confirmed) (01, 02).
- [ ] Title, caption, data date and source are inside the chart's frame, and the caption also appears on the page (02).
- [ ] Every number on the page is labelled; unknown values show "—" (02).

## Doesn't overstate

- [ ] The value axis starts at zero, or there is a stated reason it doesn't (01).
- [ ] The y range stays fixed while zooming or panning (01).
- [ ] The comparison is drawn: a control group, a normal range, or both (02).
- [ ] Any band says in words what it is ("90% OF PRE-EVENT DAYS FELL HERE") (01, 02).
- [ ] The text says how often the result happens by chance (02).
- [ ] The title is neutral if the effect is contested (02).
- [ ] Correlation is not described as cause (02).
- [ ] No members were chosen for how dramatic they look; anything left out is named, with the reason (02).
- [ ] Smoothing, bins and windows were chosen on ordinary periods, with the numbers recorded, and apply equally to the comparison band (03).

## Handles missing data

- [ ] Gaps are breaks or hatched cells, never zeros (02).
- [ ] Averages use complete periods only (02).
- [ ] Source outages are detected and shown as gaps (02).
- [ ] Every source stamps points the same way: start or end of the period (02).

## Works for everyone

- [ ] Colour is never the only cue, and there is no red/green pair (04).
- [ ] Text is at least 4.5:1 and lines at least 3:1, in both light and dark themes (04).
- [ ] The chart is focusable, arrow keys read values, and a polite live region announces them (04).
- [ ] A data table lists every number (04).
- [ ] No horizontal scroll at 375 px; labels don't overlap on phones (04).

## Survives being shared

- [ ] A cropped screenshot still shows the comparison, the date and the source (02).
- [ ] The PNG export carries the title, caption, data date, sources and site address (03).
