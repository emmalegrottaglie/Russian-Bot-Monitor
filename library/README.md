# Library: reports on Russian influence operations

Copies of published reports that this project cites, kept in one place for researchers and agents (Emma, 2 November 2026). Only documents whose terms allow redistribution are copied here; each row says why. Everything else is linked to its publisher in [docs/INFLUENCE-OPERATIONS.md](../docs/INFLUENCE-OPERATIONS.md).

The copies are unchanged. Cite the publisher, not this repository. What each report says, and what it says about LGBTQ+ people, is summarised in [docs/INFLUENCE-OPERATIONS.md](../docs/INFLUENCE-OPERATIONS.md).
